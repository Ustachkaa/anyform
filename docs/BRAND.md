# Anyform — Brand

## Name

**Anyform** — _any file, any format_. Two syllables, spells itself, works as
a verb-ish noun ("anyform it"), and describes the product without a pun.

Domain candidates, in order: `anyform.app`, `anyform.io`, `getanyform.com`,
`anyform.dev` (for the API). Run a trademark search (USPTO TESS, EUIPO,
Sakpatenti) before buying merchandise.

Names considered and dropped:

| Name | Why not |
| --- | --- |
| Convertly / Convertio-likes | Sounds like the incumbents; SEO confusion |
| Morphly | Cute but says nothing about files |
| Formshift | Good, kept as fallback #1 |
| Transmute | Fallback #2; harder to spell for non-native speakers |
| Reformat | Too generic to trademark |

## Tagline

Primary: **Any file. Any format. No nonsense.**
Alternates: "Drop it. Pick it. Done." · "The converter that doesn't waste your
time." · "10 free. No ads. Ever."

## Voice

Plain, quick, a little dry. We write like a competent colleague who has done
this a thousand times, not like a startup. Short sentences. Name the engine
that did the work. Never say "seamless", "powerful" or "unlock".

- ✅ "Converted with ffmpeg in 4.2s. 38 MB → 6 MB."
- ❌ "Your file has been seamlessly transformed!"

## Visual identity

The aesthetic is a **precision workshop label**: paper, ink and a single
hazard-yellow accent. It reads as a well-made tool rather than a SaaS
dashboard, and it is deliberately unlike every competitor (blue, red, orange
and green are all taken by Convertio, CloudConvert, Zamzar, FreeConvert and
Online-Convert).

### Colour

| Token | Value | Use |
| --- | --- | --- |
| `--paper` | `#F4F1EA` | Page background |
| `--paper-2` | `#EAE6DC` | Cards, wells, drop zone |
| `--ink` | `#14130F` | Text, primary buttons, chips |
| `--ink-2` | `#3D3A32` | Secondary text |
| `--ink-3` | `#7C7869` | Muted text, hairlines |
| `--line` | `#D6D1C4` | Borders |
| `--accent` | `#FFC900` | The one accent: highlights, progress, focus, "free" badge |
| `--accent-ink` | `#14130F` | Text on accent |
| `--ok` | `#1F8A4C` | Success |
| `--bad` | `#C8321E` | Errors |

Dark mode inverts paper and ink (`#121110` / `#EDE8DC`) and keeps the yellow.

### Type

- **Display**: _Bricolage Grotesque_ — wide, characterful, variable optical
  size. Headlines, prices, big format chips.
- **Body**: _Instrument Sans_ — clean, slightly narrow, excellent at small
  sizes.
- **Mono**: _IBM Plex Mono_ — every file extension, size, duration and engine
  name is set in mono. `.mov → .mp4` is the brand's most repeated glyph.

### Motifs

- The **arrow** `→` between two format chips, oversized in the hero.
- **Ticket edges**: job cards and receipts have a perforated (dashed) top
  edge, like a tear-off label.
- **Hairline grid** and a faint paper-grain texture on the background.
- Progress is a thick yellow bar that fills left-to-right; on completion the
  bar becomes ink and the download button becomes yellow.

### Logo

Wordmark "anyform" in Bricolage Grotesque, lowercase, with the "y" descender
drawn as a right arrow. Favicon: a yellow square with an ink `→`.
